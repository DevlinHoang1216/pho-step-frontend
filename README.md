# Phố Step - Frontend (Vue.js + Bootstrap)

Đây là phần giao diện người dùng (UI) của website bán giày sneaker nam **Phố Step**, được xây dựng bằng **Vue.js** và **Bootstrap**.

## 🚀 Công nghệ sử dụng
- [Vue 3](https://vuejs.org/)
- [Vue Router](https://router.vuejs.org/)
- [Pinia](https://pinia.vuejs.org/) hoặc Vuex
- [Axios](https://axios-http.com/) – gọi API
- [Bootstrap 5](https://getbootstrap.com/) – giao diện
